## 📖 About the Project

ASE is a student club at Nitte Meenakshi Institute of Technology for people who want to learn software engineering by building. This website introduces the club, showcases its events and team, and provides a sign-up and login interface.

Explore events such as **I-Solve**, **Code Conspiracy**, and **VibeCraft**, learn about the club’s different domains, and find out how to join.

## ✨ Features

- **Club homepage** with an animated introduction and scrolling events ticker
- **About page** featuring club information, event highlights, and team domains
- **Event showcase** with posters and event details
- **Interactive interface** with responsive navigation and image lightbox
- **Sign-up and login demo** with basic form validation

## 🛠️ Built With

- HTML
- CSS
- JavaScript

## 🚀 Getting Started

This is a static website and does not require package installation or a build step.

1. Download or clone the project.
2. Open [`home.html`](home.html) in a browser, or run the project using a local development server such as the VS Code **Live Server** extension.
3. Use the navigation links to explore the About and Login / Sign Up pages.

## 🔐 Authentication Note

The sign-up and login flow is a **front-end demo**. It stores account information in the browser’s `localStorage`; it does not use a server or secure authentication system. Do not use real or sensitive passwords with this demo.
