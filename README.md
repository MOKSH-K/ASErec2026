## 📖 About the Project

ASE (Advanced Software Engineering) is a student club at Nitte Meenakshi Institute of Technology, Bengaluru. The club brings together students interested in software, research, design, and technology.

This website introduces the club, showcases its events and team, and provides a sign-up and login demo for students who want to join.

## ✨ Features

- Club homepage with an animated introduction and scrolling events ticker
- About page with club information, featured events, and team domains
- Event showcase with posters and event details
- Responsive navigation and interactive image lightbox
- Sign-up and login demo with basic form validation

## 🛠️ Built With

- HTML
- CSS
- JavaScript

## 🚀 Getting Started

This is a static website. No package installation or build step is required.

1. Download or clone the project.
2. Open `home.html` in a browser, or run the folder using a local development server such as the VS Code Live Server extension.
3. Use the navigation links to explore the website.

## 🔐 Authentication Note

The login and sign-up pages are a front-end demo. Account information is stored in the browser's `localStorage`; there is no server or secure authentication system. Do not use real or sensitive passwords with this demo.
